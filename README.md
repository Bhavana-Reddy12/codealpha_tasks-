## 📋 TaskFlow — Project Management Tool

Implemented the TaskFlow project management application as part of the full-stack development tasks.

### ✨ Features
- 🔐 User authentication and authorization
- 📁 Create and manage projects
- 👥 Add and manage project members
- ✅ Create and assign tasks
- 🔄 Manage task status
- 💬 Add comments and communicate within tasks
- 📊 Project/task management interface
- 🗄️ Backend database integration

### 🛠️ Technology
- Frontend: HTML, CSS, JavaScript
- Backend: Django / Express.js
- Database: SQLite / MySQL / PostgreSQL

### 🎯 Purpose
TaskFlow provides a collaborative workspace where users can organize projects, assign tasks, track progress, and communicate with team members.
